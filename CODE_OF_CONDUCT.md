# Code of Conduct

fuego-os follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Everyone taking part in this repository, in issues, pull requests, discussions and reviews, is expected to follow it.

In short: be kind and patient, keep discussion about the work, and leave personal details out of logs and screenshots (Wi-Fi names, IP addresses, account names, pairing codes).

## Reporting

If someone breaks this code, tell the maintainer, [@danajerban](https://github.com/danajerban), privately, at the email address on their GitHub profile. For abuse on GitHub itself, you can also use GitHub's **Report content**. Every report is read, and the reporter's name is kept private.
